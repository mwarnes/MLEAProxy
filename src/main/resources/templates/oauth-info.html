Supported Grant Types:
  • password - Resource Owner Password Credentials Grant
  • client_credentials - Client Credentials Grant
Required Parameters:
Parameter Required Description
grant_type Yes Must be password or client_credentials
client_id Yes Client identifier (e.g., mleaproxy)
client_secret Yes Client secret (e.g., secret)
username For password grant User's username
password For password grant User's password
scope No Optional space-separated scopes
