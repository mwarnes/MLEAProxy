Usage:

This endpoint is part of a SAML 2.0 authentication flow initiated by a Service Provider (SP).

  1. The Service Provider sends a SAML AuthnRequest to this endpoint
  2. The user authenticates via the login form
  3. MLEAProxy generates a SAML Response and sends it back to the SP
Available Endpoints:
  • IdP Metadata - Download SAML metadata for SP configuration
  • Status Page - View all available endpoints and test commands
